# Contributing

1. Open an issue describing the proposed change.
2. Create a branch for your work.
3. Make a focused change and add or update tests.
4. Run `python -m unittest discover -s tests -v`.
5. Open a pull request and explain what changed.

Please do not include passwords, API keys, personal data, or local task files in commits.
# Contributing Guidelines

Thank you for your interest in contributing to Secure Study Planner!

## Requirements

- Use Python 3.10 or newer.
- Follow standard Python style conventions (PEP 8).
- Write clear, readable, and maintainable code.
- Keep the application compatible with its existing functionality.
- Include or update unit tests when adding or changing features.
- Do not commit passwords, private information, or sensitive data.

## Submitting Contributions

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes and add appropriate tests.
4. Run the existing tests:

```bash
python -m unittest discover -s tests
```

5. Submit a pull request describing your changes.

## Reporting Bugs

Report bugs and request enhancements through the [GitHub Issues page](https://github.com/ChrisPBaconctrl/SecureStudyPlanner/issues).
